════════════════════════════════════════════════════════════════════════════

   $ flutter pub get
   $ flutter run

2. JOGAR
   - Clique em "TRABALHAR" para ganhar dinheiro
   - Compre upgrades para aumentar renda
   - Veja a progressão de carreira

3. ENTENDER
   - Leia QUICKSTART.md para começar

   - Adicione features seguindo padrões

5. PUBLICAR
   - Leia PUBLISHING.md para Google Play/App Store
   - Leia MARKETING.md para estratégia
   - Use checklist pré-lançamento
